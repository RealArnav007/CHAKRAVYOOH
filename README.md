# Chakravyooh
Chakravyooh is an AI-powered tropical cyclone intelligence and resilient emergency operations platform. When disasters knock out cell towers and internet, ordinary Android phones form a self-healing mesh: encrypted distress messages hop phone-to-phone over Wi-Fi Aware/Bluetooth with no network at all, until reaching a phone with connectivity — which securely forwards them to the cloud command center. Coupled with geostationary satellite telemetry (INSAT-3DR/3DS), polar scatterometry, and oceanic buoy arrays, Chakravyooh delivers real-time storm track prediction, automated danger zone delineation, and resilient last-mile disaster warning delivery. Satellite = identify & predict. Backend = synthesize & risk-model. Chakravyooh Command Deck = act & dispatch.
